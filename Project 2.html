Second Project

In term 2 our class learned how to use spreadsheets and turn data into information. In the process we learned how to use the sheets code to organise and sort files into different categories. In response to this, we were given a set of data from topics , where we could choose from anime, music, F1, Basketball and one other. After we had chosen a topic, we were to turn the data set into information, with the data having more than 12000 lines of data in one google sheet. Along the way, there was some difficulty sorting things like anime genres as each genre combination was counted as an independent variable in a pie chart. The solution for this was filtering for the main genre of an anime.

Overall, I think this project was a good learning experience and I learned a lot about how to use spreadsheets and turn data into information.
